# 点物GEO 扩展 Changelog

## 2.11.16 — 2026-08-24

- 企鹅号：有 QQ/om Cookie 时视为已登录，不再把「Cookie 在、后台未解析」当成未登录（站点会因此打开扫码页，把已登录会话踢掉）

- 向网页报告扩展版本，站点在有新包时给出下载入口

## 2.11.8 — 2026-08-19

- 百家号等图床转存：把 `../../../public/xxx.png` 拼到站点域名上的坏地址收成可请求的根路径；拉不到时提示在编辑器里重新上传，不再假装转存成功

- 点物网站默认对接 https://dianwu.ai，设置里不再填本机或其他地址
